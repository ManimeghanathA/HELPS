HELPSs - Helicopter Emergency landing place suggestion system
I'm trying to build an prototype for this project, where first i want to take in satellite data and other required data of a specific location as a proof of concept and then extract features which are really necessary for deciding the landing of a helicopter and then store them in a database as the user selects the helicopter or enters the information about the helicopter manually, then we sort the locations as per the helicopter specifications, and list top k locations with the score

Project Objectives

The system aims to:

Analyze large geographic regions automatically.
Identify candidate emergency landing locations.
Extract terrain, surface, and obstacle information.
Evaluate locations against helicopter-specific constraints.
Rank landing zones based on operational suitability.
Provide explainable recommendations with risk factors.

Core Design Philosophy

The system does not make decisions on behalf of the pilot.

Instead, it provides:

Decision Support

rather than:

Decision Making

Output recommendations are accompanied by:

Supporting factors
Risk factors
Terrain information
Suitability scores

allowing the pilot to retain final authority.
