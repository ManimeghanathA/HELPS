# Working map decision

The user explicitly chose to retain the broader Neha candidate map rather than adopt the 191-candidate conservative experiment. The active working UI is http://127.0.0.1:8766, using the preserved 2,484-polygon source dataset with the seven existing reviewed quarantines (2,477 displayed candidates). No additional broad exclusions are to be applied to this map merely to reduce candidate count.

The 191-candidate result remains a separate experimental artifact for comparison. It was never promoted to the canonical dataset and is not the chosen replacement. Its strict SCL/NDVI and historical land-cover gates must not be presented as the accepted production policy. Future improvements should target supported obstacle errors while preserving potentially useful terrain and measuring rejection.

This choice does not validate the remaining broad-map polygons. Building/tree/water source gaps, promising rejected ground, registration and independent validation remain unresolved. Existing geometry-fidelity fixes remain in place.
